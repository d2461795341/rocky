# 🪨 Rocky Voice Synthesizer

灵感来源于安迪·威尔（Andy Weir）的科幻小说《挽救计划》（*Project Hail Mary*，2021）及其改编电影（2025）。

小说中，安迪·威尔对伊甸人声音有一段经典描述：

> "Rocky 发出的是音符。像鲸歌，但又不完全像，因为同时有好几个（音符）。我猜……是鲸鱼的和弦。"

> "一位来自波江座 40 星系的外星科学家，其音调语言的范围——对人耳来说——从最深的鲸鱼叫声到短笛的最高音符，无所不包。"

*—— 安迪·威尔《挽救计划》(2021)*

电影音效设计则由艾瑞克·阿达尔（Erik Aadahl）和伊桑·范德·林（Ethan Van der Ryn）创作，基于安迪·威尔的描述进一步发展出伊甸语（Eridian language）。

本项目的声学参数（极低基频、非整数泛音结构、钟/铃质感包络等）均**直接来自小说的描述**，而非电影音效。

## 概述

将任意文本转换为 Rocky（伊甸人）风格的外星语音音频。

**核心特性**

- **确定性输出**：相同文本始终产生完全相同的音频，种子由 SHA-256 哈希派生
- **零 AI 模型**：纯数学合成，无需任何预训练模型或神经网络
- **标点驱动韵律**：文本标点自动映射为停顿时长，塑造自然节奏
- **多入口使用**：支持 CLI 命令行和 Web UI 界面两种交互方式

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# CLI 使用
python -m src.rocky "你好 Rocky"
python -m src.rocky "Hello" --sample-rate 44100 -o output.wav

# Web UI
python ui/app.py
```

## 核心实现

```
                    文本输入 "你好 Rocky"
                           │
                           ▼
                   ┌───────────────┐
                   │ 确定性哈希    │  SHA-256 → 种子
                   └───────────────┘
                           │
                           ▼
                   ┌───────────────┐
                   │ 短语解析      │  按标点划分（。！？，；等）
                   │ 韵律参数生成  │  停顿时长 + 语速系数
                   └───────────────┘
                           │
              ┌────────────┴────────────┐
              ▼                         ▼
      ┌──────────────┐          ┌──────────────┐
      │ 音节合成     │          │ 静音填充     │
      │ (谐波+共振峰)│          │ (标点停顿)   │
      └──────────────┘          └──────────────┘
              │                         │
              └──────────┬──────────────┘
                         ▼
                 ┌──────────────┐
                 │ 全局颤音调制 │
                 │ 归一化输出   │
                 └──────────────┘
```

### 音频合成流程（单个音节）

```
基频信号 (40-80 Hz)
       │
       ▼
  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
  │ 谐波叠加 │ + │ 共振峰   │ + │ 噪声注入 │ → │ 包络塑形 │
  │ 非整数  │   │ F1/F2/F3│   │ (~0.03%) │   │ A-H-D   │
  └─────────┘   └─────────┘   └─────────┘    └─────────┘
       │              │             │              │
       └──────────────┴─────────────┴──────────────┘
                        │
                        ▼
                  输出音频片段
```

### 关键参数


| 参数   | 值                                          | 说明         |
| ---- | ------------------------------------------ | ---------- |
| 基频范围 | 40-80 Hz                                   | 极低频，像大钟的嗡鸣 |
| 基频曲线 | rocky                                      | 模拟敲击的音高变化  |
| 谐波结构 | 非整数泛音 [1, 2.1, 3.3, 4.7, 6.2]              | 钟/乐器质感     |
| 共振峰  | F1: 80-160Hz, F2: 180-350Hz, F3: 400-700Hz | 温暖低沉的音色    |
| 包络   | Attack: 8ms, Hold: 100ms, Decay: 500ms     | 敲击+长共鸣余韵   |
| 噪声   | 0.03%                                      | 几乎纯净的共鸣声   |
